It runs on your computer. The terminal, a microphone, and Telegram all reach the same assistant. What it remembers stays in a folder on that machine.

[Install](/install) it, then pick a door: the [terminal](/terminal), [voice](/voice), or [Telegram](/telegram).

[Memory](/memory) is the folder it writes. [Tools](/tools) are what it can do in the middle of a conversation. The [dashboard](/dashboard) reads the same files.
