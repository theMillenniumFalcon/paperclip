---
title: "Install"
description: "Python, a key, and one command."
---

You need [uv](https://docs.astral.sh/uv/).

```bash
uv tool install paperclip-agent
paperclip
```

The first launch creates `~/.paperclip/.env` in your user home. Put your key on `ANTHROPIC_API_KEY` in that file, then run `paperclip` again. That is the only line the default setup needs.

OpenAI and OpenRouter work too. Set `PAPERCLIP_PROVIDER` to `openai` or `openrouter`, and set the matching key: `OPENAI_API_KEY` or `OPENROUTER_API_KEY`.

Leave with Ctrl-D, or type `/quit`.
