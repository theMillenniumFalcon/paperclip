---
title: "Terminal"
description: "Type a line. Read the reply."
---

```bash
python -m paperclip
```

The banner shows where memory lives and which model is answering. Type a message and press Enter.

Empty lines are ignored. `/quit` or `/exit` stops the session. Ctrl-D does the same. Ctrl-C stops it too.

While a turn runs, short lines may appear about a tool it called or a fact it filed. The reply is the line after those.

Closing the terminal does not delete memory. The next time you start it, the same folder is still there.
